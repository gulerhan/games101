# Snake Game 🐍

React ile geliştirilmiş klasik Snake oyunu. Zorluk seviyeleri ile oynayabilirsiniz!

## Özellikler

- ✨ Modern ve kullanıcı dostu arayüz
- 🎮 Üç zorluk seviyesi: Easy, Normal, Hard
- 📊 Skor takibi
- ⏸️ Duraklat/Devam et özelliği
- 🎯 Yumuşak animasyonlar ve geçişler

## Kurulum

```bash
npm install
```

## Çalıştırma

```bash
npm run dev
```

Tarayıcınızda `http://localhost:5173` adresini açın.

## Oyun Kontrolleri

- ⬆️⬇️⬅️➡️ Ok tuşları: Yılanı hareket ettir
- Space: Oyunu duraklat/Devam ettir

## Zorluk Seviyeleri

- **Easy**: Yavaş hız (150ms)
- **Normal**: Orta hız (100ms)
- **Hard**: Hızlı (60ms)

## Build

```bash
npm run build
```

## Teknolojiler

- React 18
- Vite
- CSS3 (Modern gradient ve animasyonlar)
